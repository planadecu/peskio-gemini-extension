# Peskio extension for Gemini CLI

Tide predictions, wind and sea forecasts, water-clarity estimates and estimated fish activity for 48,000+ coastal
places across Europe, North Africa and US coasts, in 15 languages, from Peskio's public read-only MCP server
(`https://peskio.com/mcp`, no account or API key).

Install: `gemini extensions install https://github.com/planadecu/peskio-gemini-extension`

Try: "Best time to fish at Cadaqués this weekend?", "When is high tide in Saint-Malo tomorrow?", "Where near
Barcelona is best for shore fishing tomorrow?"

Guides: how to add Peskio to ChatGPT, Claude, Gemini and other assistants — https://peskio.com/en/ai-assistants ·
what the MCP server supports (tools, coverage, fair use) — https://peskio.com/en/mcp

Tide coefficients are Peskio estimates, not official values. GO / marginal / NO are conditions ratings for planning
and do not assess whether an outing is safe. Privacy: https://peskio.com/en/privacy · Terms:
https://peskio.com/en/terms · Support: info@lemurventures.xyz

Published by Lemur Ventures SL. Source of truth: the private peskio repository (`integrations/gemini-extension/`);
this public repository is a mirror for the Gemini CLI extension gallery.
